Setup
Use desktop Chrome or Edge. USB: transmit with MakeCode serial.writeValue("score", score) at 115200 baud. Bluetooth: enable UART in your program. Import the appropriate Studio Connect extension in MakeCode using its repository URL.

What do the blocks do?
Connect: initializes the selected transport, not the browser connection itself.
Send number / text: exposes a named variable to Studio. The name is a label, not automatic access to your program's memory.
Send LED display: captures the current 5 × 5 pattern.
On Studio message: receives a command string. Your code decides what happens. Register one handler and use if conditions for multiple commands.
4. Flash and connect
Download the program to your micro:bit. For USB, keep the cable connected and close other serial monitors. For Bluetooth, make sure UART is enabled and use compatible pairing settings.

Troubleshooting and limitations
Missing blocks? Import the current extension in a fresh MakeCode project. If Bluetooth fails, verify that UART service is present; radio and Bluetooth cannot normally coexist in MakeCode. A successful connection alone does not guarantee that the program handles commands. Use the round-trip test and watch the returned variable change. Actual timing is measured on the device, not by browser message arrival.
